Sincronización

¿Cómo funciona?

1. Vincula tu wearable usando la sección anterior.

2. El backend emitirá un token para tu dispositivo.

3. Tu app Flutter usará ese token para consultar estadísticas.

4. Los datos aparecerán aquí en tiempo real.

✓ Descentralizado: Angular solo muestra el estado; la sincronización se hace entre el wearable y el backend.
